## ⚡ 24/7 Cloud Execution (No Laptop Needed!)

### Option A: 24/7 GitHub Issue Bot
You can trigger iOS builds from your iPhone or any browser:
1. Go to **Issues** ➔ **New Issue**.
2. **Title**: `[Build] My iOS App`
3. **Body**: `https://mywebsite.com`
4. Click **Submit new issue**.
5. Within 2–3 minutes, GitHub Actions will package the iOS deliverables, publish them to GitHub Releases, and reply with the download links directly in the issue!

### Option B: GitHub Actions UI
1. Go to the **Actions** tab ➔ **Package Web App into iOS IPA & Safari Profile**.
2. Click **Run workflow**, enter your URL, app name, and orientation.
3. Download the 1-Tap Safari Profile, IPA, and Xcode project from **Releases** or **Artifacts**.

### Option C: 24/7 Web Studio Dashboard (Render.com)
Deploy your own 24/7 live web dashboard on Render's free tier with 1 click using `render.yaml`:
1. Log in to [Render.com](https://dashboard.render.com).
2. Click **New +** ➔ **Blueprint** and connect `thakoralpesh3/web-to-ipa-agent`.
3. Access your Web2IPA Studio live 24/7 on a public HTTPS URL.

## 🌟 Key Features
- **1-Tap Safari MobileConfig**: Instant native WebClip installation on iPhone/iPad without sideloading or certificates.
- **Standalone Sideload IPA**: Compatible with AltStore, Sideloadly, TrollStore, and Scarlet.
- **Swift / WKWebView Source**: Complete Xcode project for App Store signing.
- **Dynamic Island & Safe Areas**: Native iOS status bar and navigation bar integration.
